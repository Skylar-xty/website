Planning, Control, and Learning for Robotics

Tianyi Xia

  • Modeled MiniGrid DoorKey navigation as an MDP and used forward/backward dynamic programming to compute shortest-path policies with key pickup and door-unlocking actions.
  • Implemented segment–AABB collision checking and compared search-based (Weighted A*) vs. sampling-based planners (OMPL/RRT) for collision-free path planning in bounded 3D environments.
  • Developed safe tracking controllers for a noisy differential-drive robot with obstacle avoidance using receding-horizon CEC and GPI, evaluated in numerical simulation and MuJoCo.
