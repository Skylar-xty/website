Dynamic Pick-and-Place Challenge

Wanting Yao, Tianyi Xia, Chunyu Jiang, Yanran Yi

  • Built a perception-driven pick-and-place pipeline on a Franka Panda arm: AprilTag block detection from an end-effector camera, camera-to-base pose transformation, yaw-aligned top-down grasps solved with IK, gripper-feedback grasp validation with recovery, and incremental stacking.
  • Developed dynamic-block interception using angular-velocity prediction, pose alignment, calibration offsets, and gripper-feedback recovery for robust real-time grasping.
  • Achieved 100% success on static and dynamic blocks in simulation and ~55% on dynamic blocks in the final class competition.
